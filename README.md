## What we build

- **[sugra.ai](https://sugra.ai)** - hosted unified data aggregation API. 643+ endpoints across 75+ primary sources spanning financial markets, macroeconomics, government, physical world, and news. One API key, normalized JSON envelope, fallback chains for reliability.

- **[app.sugra.ai](https://app.sugra.ai)** - customer dashboard. API key management, usage analytics, billing, multi-factor authentication.

- **[app.sugra.ai/mcp](https://app.sugra.ai/mcp)** - Model Context Protocol server. Works with Anthropic Claude, OpenAI GPT, Google Gemini, xAI, and any MCP-enabled IDE. Available as `pip install sugra-api-mcp`.
